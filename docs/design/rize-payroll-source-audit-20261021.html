Probation start is explicitly mapped to hr.contract.pb_trial_date_start for all four countries; end remains hr.contract.trial_date_end. Start is never inferred from joining date. Historical values are copied only where the contract and ISO date are unambiguous.

Release status: implementation under validation. Live deployment and Chrome verification are recorded separately in the deployment report.
