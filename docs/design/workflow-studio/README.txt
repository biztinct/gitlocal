Build: python3 docs/design/workflow-studio/build.py
Syntax check: node --check docs/design/workflow-studio/app.js
Chrome E2E: node docs/design/workflow-studio/test-ui.cjs
  PLAYWRIGHT_MODULE may point to the installed Playwright package.
  WORKFLOW_TEST_URL selects a deployed URL instead of localhost:8842.
  WORKFLOW_SCREENSHOT_DIR optionally saves JPEGs for inspection; remove all
  screenshots generated by the test run after verification.
Live combined audit: python3 docs/design/workflow-studio/verify-live.py
Deploy committed preview: python3 docs/design/workflow-studio/deploy.py

Three views share one browser-local definition: Journey, Canvas, Blueprint.
Working interactions: create/reorder steps; move ownership; add/edit/remove empty
phases; edit typed rules and people; eligibility filters; simulated routing;
cover/access/independence/rejection scenarios; undo; local immutable snapshots;
restore and JSON export. Six fictional process templates are included.

Explicit limits: no Odoo writes, production workflow publication, live emails,
AI calls, customer records or external integration calls. Canvas positioning is
editable; edges derive from step order and simple one-step conditional branches.
Nested routing, parallel joins and durable execution are production proposals.
Stage labels are illustrative and do not create new model state values.
The proposed POC JSON schema is not an import file for the current approval engine.

The Design rationale panel contains the recommendation, repository findings,
conceptual model, implementation sequence and links to primary research sources.

Deployment adds one nginx preview route on payobook.com, following existing POCs.
It verifies committed source/build consistency and the latest combined custom
content and installed versions across the four owner-designated databases.
Unchanged modules and databases require no upgrade. Standard server addons,
retired ABM, unrelated files and other sessions' changes are preserved.
