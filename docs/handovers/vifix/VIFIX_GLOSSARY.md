# VIFIX — Vietnamese glossary (draft for the owner's review)

Generated by `docs/handovers/vifix/tools/vifix_glossary_build.py`; edit the choices there, not here.
One Vietnamese term per concept. **Variants now** are every Vietnamese our files use today for that English (with how many entries), so each fix wave knows what to replace. **Learn** is the term the Learn glossary card uses. Rows marked **REVIEW** are choices the owner should confirm (25 of 205).

Rules that apply to every term: sentence case (capitalise the first word only, plus names and legal titles); no English words inside Vietnamese except the allowlist (brand names, file types, BHXH/BHYT/BHTN, currency codes); one spelling of 'hủy/khóa' (old tone placement, as most files use).
