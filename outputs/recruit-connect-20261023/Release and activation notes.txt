Job-board core release — implemented, provider activation pending
Runtime commits: 380d41ddc, 1120744f4, 7ce93ba63, 5d02af130 and add5077c3.
Follow-up fixes cover browser request dispatch, setup guidance, review before
a tenant has configured a connection and the visible confirmation label.
- Scope remains Careers page, LinkedIn, JobStreet, VietnamWorks, employee
  referrals and agencies. SEEK is JobStreet’s API operator, not an added board.
- Payobook owns shared partner apps. Anita (anita@rize.farm) is Rize’s tenant
  contact. Payobook’s legal app owner/contact details still need confirmation.
- Server-owned partner credentials are shared across tenant databases.
  Database/company bindings restrict each tenant to its authorized organization
  or hirer. Tenant administrators cannot select another customer’s account.
  Shared secrets never appear in tenant settings or connection responses.
- LinkedIn customer-app provisioning uses the parent app, a stable tenant
  reference, encrypted child credentials and explicit pending/reconciliation
  states. Network ambiguity never triggers automatic duplicate provisioning.
- Reviewed advert drafts, queued create/update/close requests, durable claims,
  provider-confirmed listing state and background status checks are implemented.
  Closing/unpublishing a role queues provider closure; an unsent creation is
  cancelled. The UI does not claim remote closure before provider confirmation.
- Signed application callbacks are acknowledged quickly and processed by a
  background queue. Signatures, tenant/hirer identity, replay deduplication,
  SEEK delivery expiry and provider CV download origins are checked.
- Intake creates or reuses a candidate for the role/email, preserves existing
  details and CVs, tags its source and queues supported CVs for the parser.
  Raw intake is encrypted and erased after success, privacy deletion or expiry.
  Unsupported/missing CVs require an original file. No assessment/ranking is
  inferred from board data. Recruiters must review missing answers and consent.
- New connections remain disabled. Production additionally requires operator-
  recorded provider certification; this is not a substitute for completing it.
