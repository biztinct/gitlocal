CV parser: implemented, deployed and activated
- Rebuilt server verified against the authenticated Lightsail console; actual
  capacity is 4 GB RAM / 2 vCPU, Ubuntu 24.04 / Python 3.12.
- CPU Docling + spaCy and Tesseract English/Vietnamese/Indonesian OCR installed
  in a separate virtualenv. Dedicated unprivileged service account; no changes
  to Odoo's Python packages. Service enabled at boot and restart-on-failure.
- Private localhost worker behind authenticated HTTPS; external requests to
  the internal route receive 403, unauthenticated host requests receive 401.
  Root-only generated service key; encrypted company configuration in Odoo.
- CV connections checked/enabled for seven active company records across the
  four databases. All other providers retain their previous disabled state.
- One CV conversion at a time, two CPU threads, 150% CPU quota. MemoryHigh
  1900 MiB, MemoryMax 2300 MiB, swap max 256 MiB. HTTP 429/503 leaves CVs queued
  for retry; the five-minute job handles one CV per database per run.
- PDFs, DOCX and PNG/JPEG scans up to 5 MB / 30 pages. Partial/time-limited
  results fail visibly. No CV content is sent to an external AI service.
- Fixed OCR word-to-line reconstruction and Vietnamese heading recognition
  when accents are missing. Source content is preserved for review.
- Editable employer/title/year-or-month dates, current employment, education
  and configured skill mentions. Search includes CV text and reviewed profiles.
  Skill mentions never assign assessed proficiency. No invented dates, duration,
  ranking or demographic inference. Replaced CVs invalidate stale review forms;
  anonymisation clears extracted text, skills, employment and review wizards.
