Payobook — choose your interface direction

Three ways to modernise Payobook, shown across the same four workflows — Home, Payroll Run & Approval, Formula Config & Import, and Analytics & Approvals — using a fresh “Aurora” palette and a role-aware left sidebar. Each option is fully clickable: switch the role (top-right) to see the menu adapt, and navigate via the sidebar. Pick the one that feels right.

OPTION A

Skinned Native

Lowest effort · lowest maintenance

Standard Odoo lists & forms, re-skinned with the new theme (hero headers, card sections, field-edit indicators, status-driven colours) + the left sidebar. Keeps 100% of native Odoo — filters, exports, chatter.

  • Uniform across every screen
  • Survives Odoo upgrades
  • Ships fastest

OPTION B

Hybrid

Medium effort · best balance

Theme + sidebar everywhere, plus two custom cockpits for the highest-traffic flows: a Payroll-Run command centre and a Payslip review split-view. Everything else stays native.

  • Big clicks-saved on daily work
  • Native fallback for the long tail
  • Most delight per ₫
Open Option B →
OPTION C

Full Custom App

Highest effort · highest maintenance

An hr_development_ai-style single-page app — route stack, slide-in drawers, a multi-step “Run Payroll” wizard, everything bespoke. Maximum delight; native forms are replaced for core payroll.

  • “Smashing” end-to-end feel
  • Every change is hand-built OWL
  • Loses native list/export/studio
