Payobook CV extraction service — 24 Oct 2026

Activated runtime: Payobook19v2, Ubuntu 24.04, Python 3.12, 4 GB RAM / 2 vCPU.
DocuSign runs externally and requires no local signing process. This is a
bounded single-conversion deployment, not a guarantee for unrestricted load.
CPU Docling with Tesseract English/Vietnamese/Indonesian OCR uses an isolated
virtualenv, dedicated unprivileged account and persistent model cache.
Odoo's Python environment is unchanged.

Install/recover (root, authorised server):
1. Stage services/recruit_cv at /odoo/services/recruit_cv, then run
   ops/recruit_cv/install-runtime.sh. It generates a root-only service key once,
   installs the CPU runtime and records resolved packages. Preserve the key.
2. Install ops/recruit_cv/payobook-recruit-cv.service in /etc/systemd/system,
   daemon-reload and start it. Wait for authenticated /health to report ready.
   First start downloads models; later starts reuse /var/lib/recruit-cv/models.
3. Install the private nginx snippet using ops/recruit_cv/install-proxy.py
   (its staging and backup paths identify this release). Test nginx before reload.
   Only localhost and this server's static IP may use the HTTPS endpoint;
   bearer authentication is also required. External requests receive 403.
4. Run ops/recruit_cv/verify-runtime.py with the key supplied from the protected
   environment file. Acceptance dependencies additionally include reportlab.
   It creates all test documents/images in memory. Enable the systemd unit
   only after acceptance. Never print the key or put it in command arguments.
5. Run ops/recruit_cv/activate-connections.py through an Odoo shell in each
   installed database with the protected environment loaded. It checks/enables
   CV only for each active company. Other integrations remain unchanged.

Operational limits: one conversion, two CPU threads, 150% CPU quota,
MemoryHigh 1900 MiB, MemoryMax 2300 MiB, swap max 256 MiB. HTTP 429/503 keeps
jobs queued for retry; each database's cron handles one CV per run. Monitor
systemctl show payobook-recruit-cv -p MemoryCurrent -p MemoryPeak -p NRestarts
and host available memory under real concurrent Odoo use. Scale to a separate
8 GB / 4 vCPU parser host or add capacity if queues or memory pressure grow.
Partial/time-limited conversions fail visibly, never claim complete extraction.
This release's measured acceptance results are in the release notes.

Resolved Linux packages: requirements-linux.lock (CPU torch 2.13.0).

- docling-project/docling-models: fc0f2d45e2218ea24bce5045f58a389aed16dc23
Preserve the model cache for reproducible recovery; model licences are separate
from library licences. Revalidate if models or dependencies change.

The service stores no CVs or extracted content and makes no external AI calls.
Limits: 5 MB, 30 pages; one conversion at a time. Payobook stores the extracted
text and reviewed profile under its hiring access and retention rules.

New/replaced CV attachments queue extraction. Existing candidates use Extract
CV, then Review extracted CV. Skills use exact spaCy token phrases from the
configured Payobook skill vocabulary. Reviewers can add/remove matched skills;
CV mentions never assign an assessed proficiency level. Bank search includes
CV text, reviewed skills, employers, roles and education. Previously reviewed
history stays unless Replace is selected. A newer CV invalidates old reviews.

Structured employment recognises explicit employer/title labels, role-at-
employer lines and dated ranges. English/Vietnamese/Indonesian headings,
month names and current-job markers are supported. Unknown fields remain blank
with source evidence visible for correction. YYYY and YYYY-MM retain source
precision; no invented month, total duration, ranking or demographic inference.
Unrecognised layouts remain full text for human review. Customer acceptance on
representative CVs is still required; no universal extraction accuracy is claimed.
Anonymisation clears CV text, structured history, CV skills and review wizards.

Tests: python -m unittest discover -s services/recruit_cv -v
Set RECRUIT_CV_INTEGRATION=1 and install reportlab, python-docx, Pillow and httpx
for synthetic PDF/DOCX/scanned-image tests. Intel Mac testing also uses
test-macos-constraints.txt. Test images are generated in memory only.
